# MiniMax H3 film QC checklist

## Before rendering

- [ ] Exact workflow, prompt, seed, references, resolution, frames, and steps recorded
- [ ] Visible cast count and allowed/absent cast stated
- [ ] One physical instance of every allowed character
- [ ] Recurring characters and objects have canonical references
- [ ] Incoming and outgoing frame states documented
- [ ] Dialogue language and exact line documented
- [ ] Head and tail edit handles planned

## Per generated clip

- [ ] File decodes completely with video and audio streams
- [ ] Duration, frame rate, and resolution match the job
- [ ] Real-time playback reviewed
- [ ] No duplicate people, repeated faces, or extra bodies
- [ ] Identity, wardrobe, hands, limbs, and props checked
- [ ] Camera direction and object trajectories checked
- [ ] Speech transcribed and compared with the prompt
- [ ] Invented/unintelligible language noted
- [ ] Music and ambience boundary auditioned
- [ ] Opening and closing handles usable

## Whole film

- [ ] Adjacent frame boundaries reviewed
- [ ] Character and object continuity reviewed across shots
- [ ] Dialogue and score remain intelligible
- [ ] No frozen or corrupted frames
- [ ] Privacy scan completed
- [ ] Review master watched with sound
- [ ] Final render approved before export
